# PortfolioLoan

Portfolio développeur full-stack de Loan CHINCOUN.

## Lancer le projet

```bash
npm install
npm run dev
```

## Build production

```bash
npm run build
```

## À modifier

- Remplacer `TON-PSEUDO` par ton pseudo GitHub.
- Ajouter ton CV dans le dossier `public` sous le nom `CV_Loan_CHINCOUN.pdf`.
- Remplacer les liens `#` des projets dans `src/data/projects.js`.
